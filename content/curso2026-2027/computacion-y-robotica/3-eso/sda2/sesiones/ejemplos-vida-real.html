1. Las Variables

"La Mochila del Juego"

Cajas de memoria

Mundo Real:

La batería de tu móvil (0% a 100%) o el saldo de la tarjeta del autobús.

Batería: 75% Saldo Bus: 12.50 €

En el Videojuego:

La puntuación (score), las vidas (life) o las monedas recolectadas.

Visual MakeCode Bloques & Código:

Variables establecer score a 75
Info cambiar vidas por -1
// MakeCode Arcade JS (info / variables)
info.setScore(75)
info.changeLifeBy(-1)
let monedas = 0
🚦

2. Los Condicionales

"Tomar Decisiones (Si... Entonces)"

If / Else

Mundo Real:

SI la batería baja del 20%, ENTONCES el móvil activa el modo ahorro de energía.

Batería Simulada: 15% ⚡ MODO AHORRO ACTIVADO

En el Videojuego:

SI el personaje toca una moneda, ENTONCES suma +1 punto. SI NO, sigue caminando.

Visual MakeCode Bloques & Código:

si sprite se solapa con moneda entonces
cambiar score por 1
// Colisiones y Condicionales TS
sprites.onOverlap(
  SpriteKind.Player, SpriteKind.Food,
  function (jugador, moneda) {
    moneda.destroy()
    info.changeScoreBy(1)
  }
)
🔄

3. Los Bucles

"Repetir Tareas Aburridas"

Loops / Intervals

Mundo Real:

El temporizador del cepillo de dientes de 2 min o la alarma que suena cada 5 min al posponer.

Intervalo: Cada 2000 ms (2s) Repetiendo...

En el Videojuego:

Generar enemigos automáticamente cada 2 segundos en una posición aleatoria.

Visual MakeCode Bloques & Código:

al actualizar el juego cada 2000 ms
crear sprite enemigo
// Bucles temporizados MakeCode JS
game.onUpdateInterval(2000, function () {
  let enemigo = sprites.create(
    img` ... `, SpriteKind.Enemy
  )
})

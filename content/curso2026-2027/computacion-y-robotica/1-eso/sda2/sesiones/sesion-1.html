Sección 01 • Fundamentos

💻 ¿Qué es el Pensamiento Computacional?

💡

TAKEAWAY / IDEA CLAVE:

El pensamiento computacional es una forma de analizar y resolver problemas cotidianos estructurando la información como lo haría un informático, para obtener soluciones claras, creativas y ejecutables.

1.1. Concepto General

Consiste en un método para abordar situaciones complejas utilizando datos, analizando la estructura del problema y diseñando pasos ordenados para resolverlo. No implica pensar como un ordenador, sino pensar estratégicamente para que un ordenador (o una persona) pueda ejecutar una solución.

1.2. Las 4 Técnicas y Habilidades Fundamentales

N.º Técnica / Habilidad Explicación Didáctica Ejemplo Práctico
1 Descomposición Dividir un problema o sistema complejo en partes más pequeñas y manejables para resolverlas individualmente. Dividir el diseño de un videojuego en: personajes, escenarios, sonido y puntuación.
2 Reconocimiento de Patrones Identificar similitudes, tendencias o características repetitivas entre distintos problemas. Darte cuenta de que todos los juegos de carreras necesitan un contador de tiempo.
3 Abstracción Seleccionar la información realmente importante, filtrando lo esencial e ignorando detalles irrelevantes. En un mapa de metro, importar solo las paradas y conexiones, ignorando los edificios de la superficie.
4 Diseño de Algoritmos Crear un plan o conjunto de instrucciones paso a paso para resolver el problema. Escribir la receta detallada para cocinar un plato paso a paso.

1.3. Metodología de Trabajo: "Pienso - Programo - Pruebo"

Para aplicar el pensamiento computacional en el aula o en proyectos reales, seguimos tres pasos sencillos:

🧠

1. PIENSO

Analizo el reto. Aplico la descomposición y la abstracción para definir qué pasos necesito.

💻

2. PROGRAMO

Organizo la secuencia lógica de acciones escribiendo código o utilizando bloques/instrucciones.

🚀

3. PRUEBO

Ejecuto el programa, compruebo los resultados y corrijo los posibles errores (depuración).

Sección 02 • Algoritmos & Código

📜 Secuencia de Instrucciones: Algoritmo, Pseudocódigo y Programa

💡

TAKEAWAY / IDEA CLAVE:

Un algoritmo es la receta/plan, el pseudocódigo es su borrador en lenguaje humano y el programa es la traducción final a un lenguaje que la máquina entiende.

2.1. El Algoritmo

Un algoritmo es un conjunto estructurado y ordenado de instrucciones que permiten resolver un problema o realizar una tarea en un tiempo determinado.

Propiedades indispensables de un algoritmo:

Preciso

Cada paso debe ser claro y sin ambigüedades.

Finito

Debe tener un inicio y un final definidos (no dura infinitamente).

Ordenado

Las instrucciones siguen un paso a paso estrictamente secuencial o lógico.

2.2. Comparativa: Algoritmo vs. Pseudocódigo vs. Programa

Concepto ¿Qué es? ¿Quién lo entiende? ¿Se ejecuta en ordenador?
Algoritmo La idea y secuencia de pasos lógica para resolver un problema. Personas ❌ No
Pseudocódigo Lenguaje intermedio (parecido al humano) para diseñar y corregir algoritmos fácilmente. Personas (programadores) ❌ No
Programa Código escrito en un lenguaje de programación específico (Python, C, Scratch). El ordenador / Dispositivo ✅ Sí

Sección 03 • Representación Visual

📊 Representación Gráfica: Diagramas de Flujo

💡

TAKEAWAY / IDEA CLAVE:

Un diagrama de flujo representa visualmente un algoritmo usando símbolos estandarizados unidos mediante flechas de flujo.

3.1. Simbología Estándar de los Diagramas de Flujo

Símbolo Visual Nombre del Símbolo Función / Uso en el Diagrama
( Óvalo )
Inicio / Fin Señala el comienzo o la conclusión del algoritmo.
[ Rectángulo ]
Proceso Indica una acción, operación matemática o tarea a realizar.
[/ Entrada /]
Entrada / Salida Captura datos de entrada (ej. leer edad) o muestra resultados.
< Rombo >
Decisión Evalúa una condición (Sí/No) y divide el camino según el resultado.
--->
 Línea de flujo Flechas que marcan el orden estricto de ejecución de las acciones.
